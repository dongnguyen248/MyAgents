# Stage checklist: SPEC

- Every template section is present and carries real content, not placeholders.
- Each functional requirement has a stable REQ-<n> id and a testable statement.
- Every requirement is covered by at least one acceptance criterion.
- Scope states what is out of scope, not only what is in scope.
- Non-functional requirements name measurable targets where the requirement implies them.
- Open questions are genuine unknowns, not decisions the specification should make.
- Nothing in the specification contradicts the original requirement.
