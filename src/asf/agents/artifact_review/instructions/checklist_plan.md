# Stage checklist: PLAN

- The plan traces back to the SPEC: every REQ id is addressed by the approach or by a milestone.
- Milestones are sequential, and each has deliverables and acceptance criteria.
- Dependencies reference only earlier milestones.
- Impacted components match the approach; nothing is planned that the SPEC excludes.
- The testing strategy covers the SPEC acceptance criteria.
- Risks name a mitigation, not only a worry.
